# MAIN MENU · Меню в PDF

Фронтовое приложение: принимает Excel-файл с меню («Меню N неделя.xlsx») и
собирает фирменный PDF для печати в стиле сайта [main-menu](../main-menu) —
палитра, шрифты Playfair Display / Manrope, логотип в углу каждой страницы.

## Что умеет

- Разбирает видимые листы файла (скрытые листы пропускаются):
  - недельную сетку (Пн–Пт по столбцам, категории строками) → страница на каждый день;
  - список «Выход / название / Цена» (меню на Пн–Пт) → отдельная страница;
  - столбец «код название выход» (завтраки ЗОЖ) → отдельная страница.
  Столбцы ищутся по заголовкам «Выход» и «Цена», служебные «код» и количество в PDF не попадают.
- Читает КБЖУ («450/18/36/14»): столбец находится по заголовку «КБЖУ», а если его нет — по значениям.
  В PDF выводится строкой под блюдом: «450 ккал · Б 18 · Ж 36 · У 14».
- Склеивает порции одного блюда: «250 / 150 г — 47 / 27 ₽».
- Любое поле правится на месте: заголовки, разделы, блюда, состав, выход, КБЖУ, цены,
  плашка под заголовком. Можно добавлять, удалять и двигать блюда и разделы,
  отключать страницы.
- Всё сохраняется в `localStorage` браузера: файл загружается один раз,
  несколько недель хранятся рядом, есть копия и удаление.
- Настройки PDF: цены, выход и КБЖУ вкл/выкл, 1 или 2 колонки, угол логотипа,
  размер текста, кремовый или белый фон, подпись внизу.
- Живой предпросмотр и кнопка «Скачать PDF» — PDF собирается в браузере
  (`@react-pdf/renderer`), сервер не нужен.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # статический экспорт в out/
```

Проверить разбор файла без браузера:

```bash
node scripts/check-parse.mjs "путь/к/Меню 1ая неделя.xlsx"
```

## Деплой (AWS Amplify)

`amplify.yml` уже в репозитории: `npm ci` → `npm run build`, артефакты из `out/`.
В Amplify Console: New app → Host web app → GitHub → этот репозиторий, ветка `main`.

## Структура

- `src/lib/parse.js` — Excel → модель меню
- `src/pdf/MenuPdf.jsx` — шаблон PDF
- `src/components/` — интерфейс (загрузка, редактор, настройки, предпросмотр)
- `public/fonts/` — TTF-шрифты для PDF (OFL)
